## Описание парадигм
Парадигма - это функциональный подход к построению структуры программы и выполнению операций в коде. В современном мире программирования выделяют три основные парадигмы:
- **Процедурное программирование** - структурированный способ написания программ, основанный на разделении кода на процедуры (функции), которые выполняются последовательно.
- **Функциональное программирование** - парадигма, в которой программирование строится на использовании чистых функций, избежание изменяемого состояния и использовании высших функций.
- **Объектно-ориентированное программирование (ООП)** - методология, основанная на создании объектов, объединяющих данные и методы их обработки.
---
## Процедурное программирование
Процедурное программирование использует разделение программы на функции или процедуры, которые выполняются последовательно. Используется начинающими разработчиками или для обучения новому функционалу, когда программа не настолько большая чтобы использовать ООП или функциональную парадигму. Прост в реализации так как в данной парадигме минимальный уровень абстракции, что позволяет легче воспринимать программу и этапы ее работы. Также облегчает отладку
#### Преимущества:
- Простота написания и понимания.
- Легкость отладки и тестирования.
- Хорошо подходит для небольших проектов.
#### Недостатки:
- Сложность поддержки больших программ.
- Код может быть плохо структурированным.
#### Пример:
```python
# Процедурное программирование
def add_numbers(a, b):
    return a + b

def main():
    x = 5
    y = 10
    result = add_numbers(x, y)
    print(f"Результат: {result}")

main()
```

## Функциональное программирование
Функциональное программирование ориентировано на работу с неизменяемыми данными и использованием чистых функций Данная парадигма уже используется опытными разработчиками для реализации средне-больших проектов. Данная парадигма также удобна в автоматизации кода, когда одну часто выполняемую задачу можно вынести в отдельную функцию. Минусы данной парадигмы в ее не энергоэффективности, когда на каждом этапе выполнения программы идет дублирование уже использованных переменных или создание новых для реализации разделения кода на Глоубальный-Локальный доступ. Чаще всего используется вместе с ООП парадигмой для реализации вспомогательной или скриптовой части программы.
#### Преимущества:
- Улучшенная читаемость и предсказуемость кода.
- Упрощение отладки за счет отсутствия изменяемых данных.
#### Недостатки:
- Не всегда эффективное использование ресурсов.
- Высокий порог вхождения.
#### Пример:
```python
# Функциональное программирование
def square(x):
    return x * x

def main():
    numbers = [1, 2, 3, 4]
    squared_numbers = list(map(square, numbers))
    print(squared_numbers)

main()
```

## Объектно-ориентированное программирование
ООП основано на использовании объектов и классов для структурирования кода. Данная парадигма используется в 99% случаев больших проектов, когда вместо объявления множество функций и дубликатов есть определенный класс, который занимается работой с объектом и хранении информации о нем. Порог входа высокий так как используется абстрактная структура выполнения кода, что влечет за собой не четкую архитектуру выполнения программы и сложности в ее отладке. Также потребляет больше ОЗУ для хранения информации об объектах и их методах. Зачастую используется в совокупности с Функциональной парадигмой, где ООП берет на себя большие объемные задачи, а Функциональная парадигма несет за собой роль второстепенной парадигмы для выполнения скриптовой части работы программы, такими образом при разделении парадигм экономится ресурсы ПК при выполнении программы и ускорении ее работы.
#### Преимущества:
- Упрощает разработку крупных проектов.
- Позволяет создавать переиспользуемые компоненты.
- Инкапсуляция и полиморфизм улучшают читаемость кода.
#### Недостатки:
- Может приводить к усложнению кода.
- Увеличенные накладные расходы на работу с объектами.
#### Пример:
```python
# Объектно-ориентированное программирование
class Car:
    def __init__(self, brand, model):
        self.brand = brand
        self.model = model

    def display_info(self):
        return f"Автомобиль: {self.brand} {self.model}"

car1 = Car("Toyota", "Corolla")
print(car1.display_info())
```
