## История языка
- **Python** - язык программирования, созданный для упрощения работы программистов, с акцентом на читаемость кода. Главный разработчик и создатель проекта - Гвидо ван Россум из Голландии. Название язык получил в честь британской юмористической группы "Монти Пайтон". IDE языка Python называется IDLE в честь Эрика Айдла (Eric Idle), одного из участников "Летающего цирка Монти Пайтона". Первая версия языка была представлена 20 февраля 1991 года.

## Типы данных
- **str** - Строка (String), итерируемый объект
```python
# Примеры работы со строками
text = "Пример текста"  # Создание строки
print(text[0], text[1], text[2], text[3])  # Разбор строки по индексам
text = text + " Новый текст"  # Конкатенация строк
text = text * 3  # Повторение строки
print(text.upper())  # Перевод в верхний регистр
print(text.lower())  # Перевод в нижний регистр
print(text.capitalize())  # Первая буква заглавная
formatted = f"Тест номер {5}"  # f-строки
words = text.split(" ")  # Разделение строки
joined = "+".join(words)  # Объединение элементов
print(text.strip())  # Удаление пробелов
print(text.replace(" ", ""))  # Замена символов
print(text.index("м"))  # Поиск индекса
if "Пример" in text:
    print("Слово найдено")

global text  # Использование глобальной переменной text внутри тела функции / класса
```

- **int** - Целочисленный тип данных
```python
# Примеры работы с переменной INT
a = 4  # Объявление переменной
b = 8

a = a + 1  # Первый способ увеличть переменную
a += 1     # Второй способ увеличть переменную

result = a / b   # Деление
result = a // b  # Целочисленное деление (без остатка)
result = a % b   # Деление по модулю (остаток от деления)
result = a ** b  # Возведение переменной a в степень
result = a * b   # Умножение переменных
result = a - b   # Сложение переменной a с b
result = a + b   # Вычитание из переменной a 

if a == 2:    # Сравнение (РОВНО) 
elif a != 3:  # Сравнение (не РОВНО)
elif a >= 4:  # Сравнение (БОЛЬШЕ или РОВНО)
elif a <= 5:  # Сравнение (МЕНЬШЕ или РОВНО)
elif a > 6:   # Сравнение (БОЛЬШЕ)
elif a < 7:   # Сравнение (МЕНЬШЕ)
else:         # ИНАЧЕ
```

## Условные операторы (if, elif, else)
```python
num = 10
text = "Сумма"
if num > 0:
    print("Число положительное")  # Выведется, тк 10 > 0
elif num < 0:
    print("Число отрицательное")  # Не выведется, тк 10 !< 0, также уже сработал один из операторов
elif text == "Число":
	print("Это число")  # Не выведется так как уже сработал один из операторов
elif text == "Сумма"
	print("Это сумма")  # Не выведется так как уже сработал один из операторов
else:
    print("Число равно нулю")  # Не выведется так как уже сработал один из операторов

# При использовании оператора if-elif-else среди всех операторов будет выполнен всего 1 оператор

```

## Исключения (try, except, finally)
```python
try:
    num = int(input("Введите число: "))
    print(10 / num)
except ZeroDivisionError:
    print("Ошибка: Деление на ноль")
except ValueError:
    print("Ошибка: Введите число")
finally:
    print("Операция завершена")
```

## Функции
```python
# Определение функции
def my_function():
    return True
print(my_function())  # Выведет True

# Функция с параметрами
def add_numbers(a, b):
    return a + b
result = add_numbers(5, 10)  # Вызов функции
print(add_numbers(b=10, a=5))  # Передача параметров по ключу

# Функция с необязательными аргументами
def power(base, exponent=2):
    return base ** exponent
print(power(base=5))  # Выведет 5 в степени 2

# Функция с произвольным числом аргументов
def sum_all(*args):
    return sum(args)
print(sum_all(1, 2, 3, 4, 5))

# Функция с произвольными именованными аргументами
def print_info(**kwargs):
    for key, value in kwargs.items():
        print(f"{key}: {value}")
print_info(name="Иван")

# Лямбда функция (анонимная функция)
square = lambda x: x ** 2 
print(square(5)) # Выведет: 25

# Рекурсивная функция (функция которая может вызывать саму себя)
def factorial(n): 
	if n == 0: 
		return 1 
	return n * factorial(n - 1)
print(factorail(5))  # Выведет файкториал из 5
```

## Циклы
```python
# Цикл for в диапозоне от 0 до 5 (НЕ включительно)
for i in range(5):
    print(i)  # Выведет числа от 0 до 4

# Цикл for в элементах списка
lst_names = ['Федор', 'Олеся', 'Лика', 'Анна']
for item in lst_names():
	print(item)  # Выведет имена в списке от lst_names[0] до lst_names[len(lst_names)]

# Цикл while
count = 0
while count < 5:
    print(count)
    count += 1

# Бесконечный цикл while
while True:
	print('test')

break()  # Прерывание цикла и его заврешение
continue()  # Переход к следующей итерации цикла
```
